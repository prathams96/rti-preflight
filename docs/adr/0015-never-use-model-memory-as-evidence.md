# Never use model memory as evidence

The OpenAI model may interpret free text, identify Material Clarifications, formulate retrieval and calculation plans, explain Grounded Results, and prepare Filing Drafts, but its general knowledge will never support a factual Research Finding. When the Evidence Index does not support an answer, RTI Tathya will disclose the limitation and offer the appropriate next path rather than filling the gap with a plausible model response.
