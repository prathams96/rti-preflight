# Make the evidence index a core product dependency

RTI Preflight will depend on a structured backend index of Primary Public Sources rather than treating general web search as the product. The hackathon prototype may simulate this index at its intended end state with a curated corpus, provided the simulation and its boundaries are explicit; this trades immediate breadth for controlled provenance, repeatable retrieval, and the ability to evaluate whether a source actually fits the authority, geography, measure, and period requested.
