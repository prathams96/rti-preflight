# Public release certification checklist

Complete this checklist against a specific deployed commit. A checked box requires a command result, URL, screenshot, or other durable evidence linked in the release PR.

- [ ] Certified commit: `_______________________________________`

- [ ] `npm run measure:release` output is attached; Ask-route gzip budget is within 200 KB under the documented conservative method.
- [ ] Snapshot version/hash: `__________________________________`

- [ ] OpenAI model/configuration is recorded without exposing a key.

## Citizen journey smoke evidence

- [ ] NCRB derived journey reaches a grounded 16-row result and shows Gujarat's required values.
- [ ] Northern Railway journey completes OTP, fictional details, review, Demo Payment, acknowledgement, and Filing Package download.
- [ ] Provider degradation preserves input and offers recovery without a false result.
- [ ] Unsupported input shows Outside Snapshot Coverage and never claims unpublished/unavailable records.
- [ ] Citizen Override remains available after a supported result.
- [ ] English/Hindi switching preserves input, need, result, draft, and filing state.
- [ ] Smoke screenshots and browser output are attached for 360px mobile and representative desktop widths.

## Trust, privacy, and accessibility

- [ ] Prototype Details and independent-assistant disclosure are visible from every screen.
- [ ] Official links, route links, downloads, restart, and result scope controls work.
- [ ] Keyboard order, focus visibility, labels, headings, status wording, and download feedback are checked.
- [ ] Reduced-motion and Hindi wrapping are checked at 360px.
- [ ] No logs or analytics contain prompt text, evidence payloads, model responses, Filing Profile values, secrets, identifiers, or package contents.
- [ ] Network-deny evidence shows Demo Adapter cannot contact government, identity, OTP, payment, or unrelated endpoints.
- [ ] Golden suite and artifact tests pass on the certified commit.

## Scope and review

- [ ] Every P1 ticket is marked shipped or cut; no cut scenario has a seeded affordance.
- [ ] CPCB conflict remains cut unless its evidence gate is approved.
- [ ] Summary is under 250 words and contains no invented adoption, endorsement, or production claims.
- [ ] The two-minute demo runbook completes in rehearsal.
- [ ] Terra review verdict is attached and every valid finding is corrected or explicitly resolved.
