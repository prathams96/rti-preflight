# Evidence Brief PDF fonts

The combined Noto Sans Devanagari files contain the Latin and Devanagari
subsets needed by the exported Evidence Brief. They were built from the
`@fontsource/noto-sans-devanagari` 5.3.0 package with `fontTools.merge` so a
single embedded face can render mixed Hindi and English text reliably.
