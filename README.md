# RTI Preflight

RTI Preflight is an independent research and drafting assistant for occasional RTI applicants in India. It checks a curated Evidence Snapshot before helping a citizen prepare an RTI Filing Draft when a formal response remains appropriate.

This repository is the fresh implementation workspace for the RTI Preflight hackathon prototype. The architecture, product, design, terminology, and decision records in this repository are the source of truth for implementation.

## Prototype boundary

The prototype performs no real government submission, identity verification, OTP delivery, or payment. Any filing journey is explicitly simulated.

## Delivery workflow

Implementation is issue-driven and pull-request-only after this bootstrap commit. Each ticket is implemented by a Luna coding agent, reviewed from the actual diff by a Terra review agent, corrected as needed, and squash-merged only after required checks and review comments are resolved.
